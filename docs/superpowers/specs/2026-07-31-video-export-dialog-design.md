# 動画書き出しダイアログ 設計

日付: 2026-07-31

## 目的

動画保存（モザイク合成書き出し）の実行前に専用ダイアログを表示し、
フォーマット・解像度・品質をユーザーが指定できるようにする。
現状は H.264 / CRF 18 / 元サイズ固定でダイアログなしに即書き出しされる。

## スコープ

- ダイアログで指定できる項目: フォーマット（コーデック）・解像度・品質の 3 つ
- 出力先パスは現状どおり `元名_mc.mp4` 固定（変更しない）
- メタ削除はツールバーのチェックボックスのまま（画像保存と共用のため移さない）
- 選択した設定は QSettings に保存し、次回ダイアログの初期値にする

## 仕様

### フォーマット

- 選択肢: H.264 (MP4) / H.265 (MP4)
- コンテナは MP4 のまま。出力拡張子・出力先の命名規則は変更なし
- H.265 は `libx265` でエンコードし、互換性のため `-tag:v hvc1` を付与
- 音声処理（copy / AAC 再エンコード）・`+faststart`・メタ削除の既存ロジックは両コーデックで共通

### 解像度

- プリセット選択: 元のサイズ / 1080p / 720p / 480p
- プリセットは**短辺の上限**として解釈し、**縮小のみ**行う（拡大しない）
  - 例: 1920x1080 で「1080p」→ 無変換。3840x2160 で「1080p」→ 1920x1080
  - 縦動画 1080x1920 で「1080p」→ 無変換（短辺 1080 のため）
- 出力サイズは `VideoInfo` から Python 側で計算し、縦横比を維持して偶数へ丸める
  （既存 `proxy_size` と同じ流儀）
- 元動画の短辺以上のプリセットは選択肢に出さない（非表示にする）
- モザイク合成は元解像度のフレームに適用し、縮小はエンコーダ側の
  scale フィルタで行う（モザイク境界の精度を保つため）

### 品質

- スライダー（0〜100）。両端に「低容量」「高品質」のラベルを添える
- 内部で CRF へ線形マッピングする。レンジはコーデックごとに変える:
  - H.264: CRF 28（低容量）〜 14（高品質）
  - H.265: CRF 32（低容量）〜 18（高品質）
- デフォルトのスライダー位置は現行品質（H.264 CRF 18）相当とする

### 設定の永続化

- QSettings ラッパー（`Settings`）に以下を追加:
  - フォーマット（コーデック識別子の文字列）
  - 解像度プリセット（短辺上限の int。元のサイズは 0）
  - 品質（スライダー値の int）
- ダイアログ表示時に読み込んで初期値へ反映し、OK 時に保存する

## アーキテクチャ

### 変更 1: `mosaic_tool/video/ffmpeg.py`

- `ExportSettings` dataclass を追加:
  - `codec: str`（`"h264"` | `"h265"`）
  - `max_short_side: int | None`（None = 元のサイズ）
  - `quality: int`（0〜100）
- CRF マッピング関数と出力サイズ計算関数を追加（いずれも GUI 非依存・純粋関数）
- `encode_command()` が `ExportSettings` を受け取り、コーデック・CRF・scale を反映する

### 変更 2: `mosaic_tool/video/export_dialog.py`（新規）

- `ExportDialog(QDialog)`: フォーマットのドロップダウン、解像度のドロップダウン、
  品質スライダー、OK / キャンセルの `QDialogButtonBox`
- コンストラクタで `VideoInfo` と `Settings` を受け取り、初期値の反映と
  プリセットの絞り込みを行う
- accept 時に `ExportSettings` を組み立てて返し、あわせて `Settings` へ保存する
- 既存の `detect_range_dialog.py` / `setup_dialog.py` と同じ構成パターンに従う

### 変更 3: `mosaic_tool/app.py`

- `_export_video()` の冒頭で `ExportDialog` を表示し、キャンセルなら中断する
- accept で得た `ExportSettings` を `VideoExporter` 経由で `encode_command()` へ渡す
- 進捗ダイアログ以降のフロー（進捗・キャンセル・完了通知）は変更なし

### 変更 4: `mosaic_tool/settings.py`

- 上記 3 キーの読み書きメソッドを既存の流儀（`_int` / 文字列検証）で追加する

## エラー処理

- 書き出し失敗・キャンセル時の後始末（プロセス kill・書きかけ削除）は既存のまま
- H.265 エンコーダが ffmpeg ビルドに含まれない場合は、既存の
  「ffmpeg の処理がエラーで終了しました」の失敗経路で通知される（追加処理なし）

## テスト

- `encode_command()`: コーデック切替（libx264 / libx265 + hvc1 タグ）、
  CRF 反映、scale フィルタの有無のユニットテスト
- CRF マッピング: 両端と中間値、コーデックごとのレンジのテスト
- 出力サイズ計算: 縮小のみ・無変換ケース・縦動画・偶数丸めのテスト
- `Settings`: 新キーの読み書きと不正値のフォールバックのテスト
