# 自動検出の区間を対象ごとに同じ行へ並べる

- 日付: 2026-07-31
- 対象: `mosaic_tool/video/lanes.py`, `mosaic_tool/regions.py`

## 背景

自動検出は `merge_detections` が検出フレームごとに独立した区間
`[検出フレーム, 次の検出フレームの直前]` を作り、追跡は一切しない。
`session.add_intervals` は `lane=None` で追加するため、行は
`lanes.place_lanes` の「開始フレーム順に最上段の空きレーンへ詰める」規則だけで決まる。

同一フレームに複数の対象が写っていると、各フレームの検出順で
レーン 0 / 1 が入れ替わる。結果、同じ人物の区間がタイムライン上で
行から行へジグザグに飛び、どのバーがどの対象なのか目で追えない。

## 要件

1. 直前フレームの区間と位置が近い区間は、同じ行へ並べる
2. 自動検出（`RegionSource.AUTO`）の行だけを対象にする。ペン・矩形は現状維持
3. 行の数を無駄に増やさない
4. 区間が数千個あっても再構成が重くならない

## 決定事項

| 論点 | 決定 |
| --- | --- |
| 目的 | 見た目の整理のみ。トラック ID の保持や区間の統合は行わない |
| 近さの判定 | 外接矩形の IoU。最大の相手を継続とみなす |
| 継続の時間条件 | レーン末尾の `end` が新区間の `start - 1` に隣接しているときだけ。1 回でも検出が抜けたら別トラック扱い |
| 非マッチ時 | 従来どおり最上段の空きレーンへ詰める |
| 適用範囲 | `RegionSource.AUTO` のみ |

## 設計

### 1. IoU ヘルパーの共有（`regions.py`）

`regions.py` の `_iou` を `bbox_iou` として公開し、`lanes.py` から再利用する。
同じ計算を二重に持たない。`drop_duplicate_regions` の呼び出しも合わせて改名する。

### 2. 行詰め（`lanes.py`）

`place_lanes` に外接矩形を渡せるようにする。

```python
def place_lanes(
    intervals: list[tuple[int, int]],
    lanes: list[int | None],
    rects: list[QRectF] | None = None,
) -> list[int]:
```

`rects=None` のときは従来と完全に同じ動作（後方互換）。`rects` があるときは、
手動レーンの確保（既存処理）のあと、残りを次の順で置く。

1. 未確定の区間を**開始フレームごとのグループ**に分け、開始フレーム昇順に処理する
2. そのグループの `start - 1` を末尾に持つレーンを**継続候補**とする
3. グループ内の区間 × 継続候補の IoU を総当たりし、`LANE_MATCH_IOU` 以上の
   ペアを**値が大きい順に貪欲に**確定する（1 レーンにつき 1 区間、1 区間につき 1 レーン）
4. 残った区間は従来どおり最上段の空きレーンへ詰める

同一フレームに複数対象があっても 3 が 1 対 1 で高い方から取るため、
対象どうしがレーンを奪い合わない。継続候補は「そのフレームで生存中のトラック」
＝ 1 フレームの検出数程度なので、総当たりの追加コストは区間数に対して線形に収まる。

レーンごとに末尾の `(end, rect)` を保持し、`end` からレーンを引ける索引を持つ。
空き判定は既存どおり二分探索のままとする。

### 3. しきい値

`lanes.py` に `LANE_MATCH_IOU = 0.1` を置く。非マッチ時の落とし先が従来動作なので、
低めに取っても現状より悪くなることはない。検出間隔が広くて対象が速く動く場合でも
継続を拾えるよう、あえて緩めにする。

### 4. 外接矩形の供給（`lanes.py`）

`build_rows` はカテゴリが `RegionSource.AUTO` のときだけ
`vr.region.image_path().boundingRect()` のリストを `place_lanes` へ渡す。
ペン・矩形は `None` を渡し、従来の割り当てを維持する。

## テスト

`tests/test_video_lanes.py` に追加する。

- 隣接し IoU が高い区間の連鎖が同一レーンに並ぶ
- 同一フレームの 2 対象は、入力の並び順を入れ替えても行が入れ替わらない
- IoU が 0（離れた位置）なら継続扱いにならない
- 1 フレーム空くと継続しない
- 手動レーン指定が継続判定より優先される
- `rects=None` では従来と同じ割り当てになる

`_iou` は直接テストされていない（`drop_duplicate_regions` 経由のみ）ため、
改名によるテスト修正は不要。`place_lanes` の第 3 引数は省略可能なので、
既存の呼び出し側テストも変更しない。

## 非対象

- 検出区間そのものの統合（1 本の長い区間にまとめる）
- `VideoRegion` へのトラック ID 付与と、行単位の選択・移動
- ペン・矩形カテゴリへの適用
- 中心距離など IoU 以外の判定基準の併用
