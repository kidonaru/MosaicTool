# タイムラインウィンドウ設計

日付: 2026-07-30
状態: 承認済み

## 目的

動画のモザイク範囲の区間指定を大幅に見直す。現状はメインウィンドウ下部の
1 行の区間バー(`IntervalStrip`)に全範囲の帯を重ねて表示しており、範囲が
増えると帯が重なって判別・操作できない。

動画編集ソフト風の独立したタイムラインウィンドウを設け、カテゴリ別の行で
区間を一覧・編集できるようにする。

## 決定事項

### カテゴリ分類とデータモデル

- `VideoRegion` に `source` フィールドを追加する(`RegionSource` enum: PEN / RECT / AUTO)
  - ペン(STROKE)・矩形(RECT)は手描き時のツール種別で確定
  - 自動検出(`add_intervals` 経由)は形状が RECT でも POLYGON でも `"auto"`
  - RegionKind だけでは手描き矩形と自動検出矩形を区別できないため由来を持つ

### タイムラインウィンドウ(新規 `video/timeline_window.py`)

```
┌ タイムライン ────────────────────────────┐
│        │ ルーラー(フレーム目盛り + 再生ヘッド)   │
│ ペン    │ ▓▓▓▓      ▓▓▓▓▓                  │ ← 重ならない区間は同じ行
│        │      ▓▓▓▓▓▓                       │ ← 重なる場合だけ行を追加
│ 矩形    │   ▓▓▓▓▓▓        ▓▓▓              │
│ 自動検出 │ ▓▓ ▓▓ ▓▓ ▓▓ ▓▓ ▓▓ ▓▓            │
└─────────────────────────────────────┘
```

- 左端に固定のカテゴリラベル列、右側が横スクロール領域
- 行はカテゴリ単位(ペン / 矩形 / 自動検出)。カテゴリ内はレーン詰めで
  「重ならない区間は同じ行」にまとめ、重なるときだけレーンを増やす
  - レーン詰め: 開始フレーム順にソートし、min-heap で「最も早く終わるレーン」へ
    割り当てる区間パーティショニング O(n log n)(自動検出はフレームごとの
    独立区間で数千個になり得るため線形走査は避ける)
- 空のカテゴリは行ごと非表示
- 再生ヘッドが可視範囲外に出たらスクロールして自動追従
- 描画は `IntervalStrip` と同じく QPainter による自前描画
  (QGraphicsView は横だけズームする用途に合わず不採用)
- paintEvent では可視範囲(event.rect())に掛かるバーだけ描画する
  (区間が数千個あってもスクロール・シークが重くならないようにする)

### 操作

- 区間バー端ドラッグ: 開始/終了フレームを伸縮(既存の区間バーと同等)
- 区間バー中央ドラッグ: 区間を長さ維持のまま平行移動
- 区間バークリック: 対応する範囲をキャンバスで選択(未表示ならゴースト表示)。
  選択中のバーは強調表示
- Delete キー: 選択中の範囲を削除(キャンバス側とも同期)
- ルーラーのクリック / ドラッグ: シーク
- Ctrl+ホイール: マウス位置を基準に横ズーム(px/フレームを変更して再描画)

### 既存 UI の整理

- 下部 `TimelineBar` から `IntervalStrip` と「区間: n〜m」ラベルを撤去し、
  シークスライダー・コマ送り・フレーム表示・検出間隔だけ残す
- メインウィンドウ下部は全体のシーク、タイムラインウィンドウは
  横スクロール + ズームで詳細を見る役割分担
- タイムラインウィンドウは動画を開いたら自動表示、動画を閉じたら非表示。
  手動で閉じた場合はツールバーから再表示できる
- シーク位置は下部バーとウィンドウで双方向同期

### 同期の流れ

- 既存の `sync_from_canvas` 機構はそのまま利用する
- 範囲/選択/フレーム変化時に全区間(source つき)と選択状態をウィンドウへ
  渡し、レーン詰めと再描画をやり直す(全再計算で十分な規模)
- ウィンドウ側の編集(伸縮・移動・削除・選択)は app 経由でセッションと
  キャンバスへ反映する

## テスト

- レーン詰めロジック(純関数化): 重なり判定・レーン割り当て
- source 分類: ペン / 矩形 / 自動検出それぞれの追加経路でカテゴリが付く
- 座標変換(フレーム↔X)とズームのクランプ
- app 連携(伸縮・移動・削除・クリック選択がセッションへ反映される)
