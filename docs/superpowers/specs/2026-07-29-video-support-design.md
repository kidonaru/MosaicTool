# 動画対応 設計書

日付: 2026-07-29
ステータス: 承認済み(実装計画待ち)

## 目的

MosaicTool で動画ファイルにもモザイクをかけられるようにする。
主ユースケースは「自動検出で全編を一括処理し、検出漏れをフレーム修正してから書き出す」。

## ワークフロー

1. 動画ファイル(mp4 等)を開くと動画モードに切り替わり、最初のフレームをキャンバスに表示する
2. 「自動検出」を実行すると全フレームを走査し、検出結果を区間つき範囲として生成する
3. タイムラインをシークして結果を確認し、検出漏れは手動で範囲を追加して区間(開始/終了フレーム)を指定する
4. 書き出しで各フレームにモザイクを合成し、音声を維持したまま `名前_mc.mp4` へ保存する

既存の画像編集フローは変更しない。キャンバス・範囲編集・モザイク処理(`make_mosaic_image`)・
検出ワーカー(`detect/worker_main.py`)は流用する。

## 動画 I/O

基盤は ffmpeg。ONNX ランタイムと同じ方式で、セットアップ時に ffmpeg バイナリを
`runtime` フォルダへダウンロードする(既存 `ModelDownloader` / セットアップダイアログ基盤を流用)。

- 読み込み: ffmpeg でフレームを rawvideo として pipe 取得する。シーク表示は該当フレームのみ抽出する
- 書き出し: モザイク済みフレームを pipe で ffmpeg へ渡し H.264 エンコードする。
  音声は元動画からストリームコピーし、mp4 コンテナに載らないコーデックのときだけ AAC へ再エンコードする
- 出力コンテナは mp4 に統一する
- メタ情報の扱いは既存の「メタ削除」設定に従う(ON のときは ffmpeg 側でメタデータを引き継がない)

## データモデル

既存 `Region` に区間情報を持たせた `VideoRegion` を追加する。

- `region: Region` — 形状・変形は既存モデルをそのまま使う
- `start_frame: int` / `end_frame: int` — 適用区間(両端含む)
- フレーム番号 → 適用範囲の解決は区間の包含判定で行う

区間内の全フレームに同じ形状・位置で適用する(キーフレーム補間はスコープ外)。

## 自動検出パイプライン

- フレームを一時画像に書き出し、既存ワーカーへ順次リクエストする(ワーカー本体は無改造)
- 検出間隔は設定可能。既定は全フレーム、長尺向けに N フレーム間隔も選べる。
  間隔検出時は検出フレームの区間を間隔ぶん前後へ広げて漏れを防ぐ
- 時間方向マージ: 隣接する検出フレーム間で外接矩形の IoU が高い検出を同一対象とみなして
  1 つの区間範囲に連結し、区間の前後にパディング(既定 5 フレーム)を付与する
  (検出のちらつきと、対象の出入りの瞬間の漏れを吸収する)

## UI

- キャンバス下にタイムラインを追加する: スライダー + フレーム番号表示 + コマ送りボタン。
  動画モードでは ←/→ キーをフレーム移動に転用する(画像モードの前後移動と同じキー)
- 範囲選択時に、区間の開始/終了を「現在フレームに設定」できる小 UI を出す
- 書き出しはプログレスダイアログを表示し、キャンセルできる

## エッジケース

- 音声なし動画: 映像のみ書き出す
- 可変フレームレート: ffmpeg の CFR 変換で固定フレームレートに正規化して扱う
- 長尺動画: 検出間隔設定と、全フレームをメモリへ載せない逐次処理で対応する
- 書き出し途中キャンセル: 中間ファイルを削除する
- ffmpeg 未セットアップで動画を開いた場合: セットアップダイアログへ誘導する

## テスト

- ユニットテスト: 区間マージ(IoU 連結・パディング)、フレーム → 範囲解決、ffmpeg コマンド組み立て
- 動画の実 I/O と GUI 操作は手動確認とする

## 実装フェーズ

1. 基盤: 動画読み込み + タイムライン + 手動区間指定 + 書き出し
2. 自動化: 全編検出 + 時間方向マージ

## スコープ外

- キーフレーム補間(区間の始点・終点で形状を変えて中間を補間する機能)
- 物体トラッキングによる範囲の自動追従
- mp4 以外への書き出し
