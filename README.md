# MosaicTool

画像・動画の指定範囲にモザイクをかけるツール。

https://github.com/user-attachments/assets/b727d54e-397f-4e7a-adb6-37318c6c51df

## 導入

[Releases](https://github.com/kidonaru/MosaicTool/releases) から使用中の OS 向けのファイルをダウンロードし、展開します。インストールは不要です。

| OS | ファイル | 起動方法 |
|---|---|---|
| Windows | `MosaicTool-v<バージョン>-win-x64.zip` | 展開して `MosaicTool.exe` を実行 |
| macOS (Apple Silicon) | `MosaicTool-v<バージョン>-mac-arm64.zip` | 展開して `MosaicTool.app` を実行(`/Applications` へ移動しても構いません) |

画像ファイルまたはフォルダは、アプリのアイコンへのドラッグ&ドロップ、コマンドライン引数、ウィンドウ(画像の上を含む)へのドラッグ&ドロップのいずれでも開けます。編集中に画像ファイルをドロップすると編集リストの末尾へ追加され、フォルダをドロップした場合は開き直します。

macOS で「開発元を確認できないため開けません」と表示される場合は、`MosaicTool.app` を右クリックして「開く」を選ぶか、以下を実行してください。

```
xattr -dr com.apple.quarantine /path/to/MosaicTool.app
```

## 操作

| 操作 | 方法 |
|---|---|
| ズーム | ホイール / トラックパッドのピンチイン・アウト / Ctrl(Cmd)+2 本指スクロール |
| スクロール | 右ドラッグ / 中ボタンドラッグ / トラックパッドの 2 本指スクロール |
| 自由範囲 | 「ペン」モードで空き領域をドラッグ(太さ指定可) |
| 矩形範囲 | 「矩形」モードで空き領域をドラッグ |
| 移動 | 範囲をドラッグ(どのモードでも可) |
| 拡大縮小・変形 | 選択して四隅/各辺中央のハンドルをドラッグ(Shift で縦横比を保持) |
| 回転 | 選択して上部の丸ハンドルをドラッグ |
| 削除 | 選択して Delete / BackSpace |
| 取り消し | Ctrl+Z / Cmd+Z |
| 保存 | Ctrl+S / Cmd+S |
| 自動検出 | 「自動検出」ボタン / D キー(自動検出ウィンドウを開閉) |
| タイムライン | 「タイムライン」ボタン(動画モードのみ。区間指定ウィンドウを表示) |

### ショートカットキー

| キー | 動作 |
|---|---|
| 1 | ペンモードへ切替 |
| 2 | 矩形モードへ切替 |
| ← | 前の画像へ(動画では前のフレームへ) |
| → | 次の画像へ(動画では次のフレームへ) |
| Tab | プレビュー(範囲のアウトラインを隠す)の ON/OFF |
| Delete / BackSpace | 選択中の範囲を削除 |
| Ctrl+Z / Cmd+Z | 取り消し |
| Ctrl+S / Cmd+S | 保存 |
| D | 自動検出ウィンドウの開閉(トグル) |

保存以外は、キャンバス(画像表示部)にフォーカスがある間だけ有効です。ツールバーの数値入力中はその入力が優先されます。

## 保存先

- ファイル単体: 同じ場所に `名前_mc.拡張子`
- フォルダ: 隣に `フォルダ名_mc/` を作成し 1 枚ごとに保存(保存後、自動で次の画像へ)

モザイクサイズは 5〜100px(5px 刻み)、1 枚の画像内で共通です。
しきい値(0〜100%、既定 10%)は、マスの被覆率がこの値以上のときにそのマス全体をモザイクにします。
下げると範囲の縁がはみ出しやすく、上げると内側に締まります。

## 自動検出 (任意)

YOLO 形式の検出モデルで、モザイク範囲を自動で追加できます。

1. ツールバーの「自動検出」(または `D` キー) を押すと自動検出ウィンドウが開きます
2. 初回は「セットアップ」を押します。推論用の実行環境と、標準の検出モデル 2 件
   (顔・目 / 合計 約 13MB) がダウンロードされます

   | OS | 実行環境の容量 | 置き場所 |
   |---|---|---|
   | Windows | CPU 版 約 250MB / GPU 版 約 2.5GB | `MosaicTool.exe` と同じ場所の `runtime` / `models` フォルダ |
   | macOS | 1 通りのみ(Apple Silicon の GPU を自動で使います) | `~/Library/Application Support/MosaicTool/` の `runtime` / `models` フォルダ |
3. 使うモデルにチェックを入れ、モデルごとに信頼度 (%) を決めて「検出実行」を押します
4. 複数クラスを持つモデルは「クラス…」を押すと、検出対象のクラスを選べます
   (初期状態はモデルの全クラスが対象です)
5. 「全ファイルに実行」を押すと、確認のうえ開いている全画像に検出と保存を順に行います

信頼度を下げると検出されやすくなります。適切な値はモデルによって違うため、
一覧の初期値は実際に検出させて決めた推奨値です。

検出結果の扱い:

- 通常の範囲と同じように移動・変形・削除でき、`Ctrl+Z` 一回でまとめて取り消せます
- 既に引いてある範囲は消えません
- 既にある範囲とほぼ重なる検出は追加されないため、検出を繰り返しても同じ範囲は増えません

### 標準モデル

[Anzhc/Anzhcs_YOLOs](https://huggingface.co/Anzhc/Anzhcs_YOLOs) (AGPL-3.0) のセグメンテーションモデルです。

| モデル | 対象 | サイズ |
|---|---|---|
| `Anzhc Face seg 640 v4 y11n.pt` | 顔 | 5.7MB |
| `Anzhc Eyes -seg-hd.pt` | 目 | 6.6MB |

### NSFW 検出モデル

NSFW 向けのモデルは自動ダウンロードの対象外です。以下の 1 件で 2D イラストの主要な対象を
まとめて検出できます。

| モデル | 対象 | 入手先 | 推奨信頼度 |
|---|---|---|---|
| Anime NSFW Detection (ADetailer All-in-One) | NSFW 領域 (複数クラス) | [Civitai 1313556](https://civitai.com/models/1313556) (要ログイン) | 15% |

`yolov11s-seg` ベースのセグメンテーションモデルで、2D イラストのみで学習されています
(検出対象の内訳と派生版は配布元を参照)。

導入手順:

1. zip で配布されるため、展開した `.pt` を `models` フォルダへ置きます
2. 自動検出ウィンドウの「更新」を押すと一覧に現れます

複数クラスをまとめて検出するモデルなので、対象を絞りたいときは一覧の「クラス…」から
検出するクラスだけにチェックを入れてください (選択はモデルごとに保存されます)。

`task=segment` のモデルは多角形の範囲になり、`task=detect` のモデルは矩形になります。

ライセンスについて:

- モデルのライセンスはそれぞれの配布元に従います
- MosaicTool 本体は MIT です
- モデルと推論環境は同梱せず実行時に取得するため、本体のライセンスには影響しません

バージョンを更新するときは、旧フォルダの `runtime` と `models` を新しい展開先へコピーすると、
実行環境とモデルを再ダウンロードせずに済みます。

## 動画 (任意)

動画ファイル (mp4 / mov / mkv / webm 等) をドロップすると動画モードになり、
静止画と同じ操作でモザイク範囲を編集できます。

初回は変換用の実行環境 (ffmpeg) のセットアップを促されます。静的ビルド
(Windows 約 110MB / macOS 約 50MB) をダウンロードし、`runtime/ffmpeg` フォルダへ
配置します (取得内容は SHA-256 で検証されます)。

使い方:

1. 動画を開くとキャンバス下にタイムラインが出ます。スライダーや `←` / `→` で
   フレームを移動できます
2. 同時にタイムラインウィンドウが開きます (閉じた場合はツールバーの
   「タイムライン」で開き直せます)。範囲には適用区間 (開始/終了フレーム) があり、
   ここで区間バーとして表示・編集します。行はカテゴリ単位 (ペン / 矩形 / 自動検出)
   で、重ならない区間は同じ行にまとまり、重なる場合だけ行が増えます
   (手動で追加した範囲の区間は、最初は追加したフレームのみです)。
   キャンバスに出るのは表示中フレームに掛かる範囲だけで、区間外のフレームへ
   移動すると選択が解除され表示からも消えます (区間そのものは残るので、
   区間内に戻れば再び現れます)

   | 操作 | 動き |
   | --- | --- |
   | バーをクリック | クリックした位置のフレームへ移動し、対応する範囲を選択 (選択中のバーは濃く表示され、両端に白いハンドルが出ます) |
   | 選択中のバーの端をドラッグ | 区間の伸縮 (開始/終了フレームの変更) |
   | バーの中央をドラッグ | 区間の平行移動 (長さを保つ) |
   | `Delete` / `Backspace` | 選択中の範囲を削除 |
   | ルーラー (上端) をクリック / ドラッグ | シーク |
   | `Ctrl` + ホイール | 横方向のズーム (カーソル位置のフレームを保ちます) |

3. 「自動検出」を実行すると全編のフレームを走査し、検出 1 件ごとに
   [検出フレーム, 次の検出フレームの直前] の区間つき範囲を追加します
   (フレームごとに独立で、別フレームの検出結果には影響されません。
   セグメンテーションモデルは輪郭の多角形、検出のみのモデルは矩形になります)
4. キャンバス下のタイムラインの「検出間隔」を増やすと、間引いて検出して高速化できます
   (漏れやすくなるため、動きの少ない動画向け)
5. `Ctrl+S` / `Cmd+S` で書き出します。同じ場所に `名前_mc.mp4` として保存され、
   音声はそのまま引き継がれます (mp4 に載らない音声形式のみ AAC へ変換)

制限事項:

- 書き出しは H.264 / mp4 固定です
- 可変フレームレートの動画は平均フレームレートに固定して扱います
- 区間内は同じ位置・形状で適用されます (フレーム間の補間はありません)

## 設定の保存

以下はアプリ設定として保存され、次回起動時に復元されます(Windows ではレジストリ `HKEY_CURRENT_USER\Software\MosaicTool\MosaicTool`)。

変更の都度、即時保存されるもの:

- モザイクサイズ
- しきい値
- ペン太さ
- 自動保存の ON/OFF
- メタ削除の ON/OFF(既定は OFF。ON にすると Exif / ICC プロファイル等を引き継がずに保存する)
- ツールモード(ペン / 矩形、既定はペン)
- 検出モデルごとの ON/OFF と信頼度

終了時に保存されるもの:

- ウィンドウの位置とサイズ
